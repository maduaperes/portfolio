# Portfolio

## Visão Geral
Este repositório armazena o código-fonte do meu portfólio profissional pessoal. A aplicação é uma Single Page Application (SPA) responsiva que centraliza minha apresentação profissional, minhas competências técnicas e os principais projetos de software desenvolvidos, servindo como ponto de contato para recrutadores e parceiros de tecnologia.

---

## Funcionalidades Principais
* **Navegação Dinâmica:** Rolagem suave através de seções integradas para melhorar a experiência do usuário (UX).
* **Alternância de Tema (Dark/Light Mode):** Controle interativo de interface para adaptação visual de preferência do usuário.
* **Menu Mobile Reativo:** Menu lateral em cascata otimizado para navegação em telas de dispositivos móveis.
* **Componentes de Efeito Visual:** Efeitos de digitação dinâmica (Typewriter) e revelação de conteúdo sob demanda via rolagem (Scroll Animation).
* **Integração de Canais de Contato:** Links diretos estruturados para redes profissionais, e-mail e mensageria instantânea.

---

## Tecnologias e Bibliotecas Utilizadas
* **Estruturação de Conteúdo:** HTML5 Semântico
* **Estilização e Layout:** CSS3 Avançado (Flexbox, CSS Grid, Animações Customizadas e Design Responsivo)
* **Lógica de Comportamento:** JavaScript Nativo (Vanilla JS)
* **Bibliotecas de Terceiros:**
  * **jQuery (v3.7.1):** Utilizado para facilitação de manipulação de eventos e transições de interface.
  * **ScrollReveal:** Responsável pelos efeitos de animação e exibição gradual dos elementos na tela.
  * **Font Awesome (v6.5.1):** Provedor do ecossistema de ícones vetoriais da aplicação.
  * **Google Fonts:** Integração das famílias tipográficas Poppins e Fira Code.

## Seções da Aplicação

### 🔷 Home (Hero)

Área de introdução com mensagem de boas-vindas acoplada a um efeito de máquina de escrever para a descrição profissional, além de botões de chamada para ação (Call to Action).

### 🔷 Sobre Mim

Breve histórico profissional detalhando minha atuação como Desenvolvedora Full Stack Júnior, objetivos de carreira e abordagens técnicas de resolução de problemas.

### 🔷 Habilidades Técnicas

Mapeamento de competências tecnológicas com foco em:

* HTML5 (Estruturação Semântica) e CSS3 (Flexbox/Grid/Responsividade).
* JavaScript (Manipulação de DOM e consumo de APIs assíncronas).
* Node.js (Desenvolvimento de APIs RESTful).
* SQLite (Gerenciamento e persistência em bancos de dados relacionais).
* Git e GitHub (Controle de versão e colaboração).

### 🔷 Projetos (Cases)

Seção dedicada à exibição dos sistemas desenvolvidos, destacando o ecossistema do **TaskManager** (aplicação full stack com banco de dados SQLite e API REST).

### 🔷 Contato

Área voltada à conversão e networking, unificando canais de comunicação direta através de e-mail e plataformas integradas.

## Como Executar o Projeto Localmente

1. **Clonar o repositório:**
```bash
git clone [https://github.com/maduaperes/portfolio.git](https://github.com/maduaperes/portfolio.git)

```


2. **Navegar até a pasta raiz:**
```bash
cd portfolio

```


3. **Executar a aplicação:**
Abra o arquivo `index.html` diretamente em seu navegador ou utilize extensões de servidor estático local, como o **Live Server**, para habilitar o recarregamento em tempo real durante modificações de código.
